# GydroRocket - многоступенчатая гидроракета с активной системой стабилизации и спасения

## Цель проекта
Разработать многоступенчатую ракету включающую в себя:
1) Моделирование полета до непосредственного запуска
2) 2-х фазную систему спасения, со сбросом оптикателей
3) Систему стабилизации
4) Систему дистанционного запуска

## Статус проекта
**Этап 1: моделирование для настройки PID и расчета запуска ракеты** (В процессе)
